# Codex · leia isto primeiro

1. Abra `docs/ponte/codex/STATUS.md` e veja qual é a próxima tarefa com status `TODO`.
2. Abra **só essa** tarefa (ex.: `02-….md`) e execute o que está escrito.
3. Não edite arquivos de `docs/copy/` nem `docs/ads/` (são do Claude).
4. Não mergeie em `main`, não faça deploy Pages, não altere DNS.
5. Ao terminar: mude o status da tarefa para `DONE`, atualize `STATUS.md`, commit `codex: …`, push na branch atual (`feat/ponte-tarefas` ou a que o Bruno indicar).
6. Se faltar dado do Bruno (preço, WhatsApp, Pixel), use placeholders e anote em `PLACEHOLDERS.md` — não invente.

Contexto: `docs/contexto/pesquisa-dtf-vendas-out-dez-2026.md` e `docs/contexto/projeto-influenciadores-vendedores-ia.md`.
